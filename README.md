# Tender Care Respite Services

Professional responsive website for **Tender Care Respite Services**, Edmonton, Alberta.

## Production website

**Primary domain:** https://tendercarerespiteservices.com/  
**WWW alias:** https://www.tendercarerespiteservices.com/

The repository is configured for GitHub Pages with the custom domain through the root-level `CNAME` file.

## Site structure

- `index.html` — Home
- `about.html` — Mission, vision, values and goals
- `services.html` — Complete service offering and service-scope guidance
- `families.html` — Who we serve and how care begins
- `team.html` — Professional team structure
- `careers.html` — Careers and applications
- `policies.html` — Scheduling, cancellation and service-scope policies
- `intake.html` — Privacy-conscious family intake worksheet
- `contact.html` — Phone, email, full address, directions and map
- `assets/styles.css` — Core responsive design system
- `assets/system.css` — Mobile/system optimization layer
- `assets/script.js` — Navigation, loader, interaction and intake utilities

The original Tender Care logo is used directly from `Tender Care logo.png`.

## GitHub Pages

**Branch:** `main`  
**Folder:** `/(root)`  
**Custom domain:** `tendercarerespiteservices.com`

DNS should point the apex domain to GitHub Pages A/AAAA records, while `www` should be a CNAME to `Mdanson27.github.io`.
